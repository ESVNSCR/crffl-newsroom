# Reporter Portraits

Place the image files for the four CRFFL Times-Herald columnists in this directory:

- `marcus-vance.png` (or `.jpg`) - Dr. Marcus Vance (Data Desk / Power Rankings)
- `buck-callahan.png` (or `.jpg`) - Buck Callahan (The Look-Ahead Desk / Matchup Previews)
- `marty-sullivan.png` (or `.jpg`) - Marty Sullivan (The Tuesday Recap)
- `chloe-carmichael.png` (or `.jpg`) - Chloe Carmichael (The Spin Room / Transactions)

Any file placed in `public/reporters/` is automatically accessible in Next.js at `/reporters/<filename>`.
